# Hand Tracking with MediaPipe & OpenCV

i built this for portfolio yes there is ai assist

## Requirement
* Python 3.11+
* Camera

## Install libraries
```bash
pip install opencv-python mediapipe
```

## Download Model
* ดาวน์โหลดไฟล์ `hand_landmarker.task` จาก [Google MediaPipe Model](https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/1/hand_landmarker.task)
* นำไฟล์วางไว้ในโฟลเดอร์โปรเจกต์

## Usage
```bash
python cv_01.py
```
